## 合并动机

之前状态：每个会话独立导出到自己的 `exported/<时间戳>/`，同一字的多个手写样本也散在多个会话里。
这就导致两个长期问题：

1. **字库覆盖率低**：之前用 `c556f452/exported/20260912_172216`（741 PNG / 191 字），仅覆盖目标文档 98.53%。
2. **变体碎片化**：「的」的 25 份样本里大部分散在 5 个会话里不互通，每次只能取第一份。

合并后这两个问题一次性解决。

## 重建过程

### 拷入 `build_personal_ttf.py`

原工具在 gaudi-font-preprocess 那边（`scripts/build_personal_ttf.py`），拷入本项目 `scripts/build_personal_ttf.py`，包装：

- 默认 `--export-dir` 指向 preprocess 项目的 `data/sessions/all_characters/`
- 默认 `--out` 指向本项目 `font/my_personal_font.ttf`
- 文件头加了一段注释说明来源 / 拷贝日期 / 包装变更

只改了默认路径，**算法 / 度量 / 输出字体格式 100% 沿用原版**（包括它"矩形拼接不描平滑"的手写笔触取舍、`整张画布线性映射到 0.9 em` 标定、`lsb == xMin`、`advance = upm`）。

### 跑出新 TTF

```bash
python scripts/build_personal_ttf.py
# 输入目录：G:\...\data\sessions\all_characters
# 唯一字符数：1432
# 生成字形：1432 个（+ .notdef）
# 已写出：font\my_personal_font.ttf（14,204,924 bytes）
```

校验全过：family=我的书法、unitsPerEm=2048、字形名规范 `uniXXXX`、字宽 [2048]、lsb == xMin ✓。

### 重建变体字体

```bash
python scripts/build_variant_ttf.py \
    --base-ttf font/my_personal_font.ttf \
    --images-dir "G:\...\data\sessions\all_characters" \
    --out font/my_personal_font_variants.ttf \
    --map-out font/variant_map.json
# PNG 3,121 张 → 1,432 个码点，其中 914 个码点有变体
# 总变体数: 1,689
# PUA 码点占用: 1,689 / 6,400
```

四项验证全过：cmap 1432→3121、主字形轮廓逐指令一致 1432/1432、变体 advance/lsb 1689/1689 与主字形一致。
